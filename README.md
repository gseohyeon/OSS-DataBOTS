## 저장소 구성

- `README.md` : 팀 소개 및 저장소 안내
- `members` : 각 팀원의 개인 활동 기록
- `meeting` : 팀 회의 및 공동 활동 기록

## 활동 방법

각 팀원은 자신의 활동 내용을 직접 Markdown 파일에 작성합니다.

활동을 진행한 후에는 자신의 GitHub 계정으로 직접 Commit하여 기록을 남깁니다.
