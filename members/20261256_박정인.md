# 박정인

- 학번: 20261256
- 이름: 박정인

간단한 소프트웨어 앱을 만들기 위한 아이디어 공유

1. 주제 선정
주제: 강의계획서 자동 분석 및 학기 일정 관리 앱

선정 이유:
대학생은 학기 초마다 과목별 강의계획서를 읽고 시험·과제 비중, 출석 규정, 주차별 일정 등을 정리해야 함.
강의계획서는 PDF나 문서로 되어 있고 양식이 과목마다 달라서 한눈에 비교하기 어렵다.
AI가 문서에서 핵심 정보를 뽑아 정리해 주면 이 시간을 크게 줄일 수 있고 도움이 많이 된다.
많은 대학생들이 겪는 문제라서 실제로 쓸 사람이 많을 것 같다.

기대 효과:
과목별 평가 비중과 일정을 한 화면에서 편하게 확인 가능
여러 과목의 마감일이 몰리는 주를 미리 알 수 있다.
출석, 결석 허용 횟수 같은 놓치기 쉬운 규정을 정리해서 볼 수 있다.

2. 만들 것

기능 목록
핵심	강의계획서 pdf 파일이나 텍스트 업로드
핵심	핵심 정보 추출	과목명, 교수, 평가 비중, 출석 규정 등 정보를 정리
핵심	주차별 일정 정리	시험과 과제 일정을 표로 만들어서 한눈에 보기 쉽게 해줌
확장	여러 과목 통합	과목들을 합쳐 학기 전체 캘린더 만들기
확장	일정 몰림 경고	같은 주에 시험·과제가 겹치면 알려줌

작동 흐름
사용자가 강의계획서를 업로드하면
프로그램이 PDF에서 텍스트를 추출하고
생성형 AI가 정해진 항목을 JSON 형식으로 뽑은 후
결과를 표와 차트로 보여 준다.

사용 기술
화면 : Python	코드가 짧고 빨리 만들 수 있다
PDF 읽기 : pdfplumber	텍스트 추출이 쉽다
AI 분석 : Claude API 또는 GPT API	학습 없이 정보를 추출할 수 있다
데이터 정리 :	pandas	표와 일정 계산에 편하다
협업 :	GitHub	코드와 문서를 함께 관리

3. 역할 분담
A (팀장/기획)	전체적인 관리	일정 관리, 요구사항 정리, 보고서·발표
B (AI 담당)	정보 추출	프롬프트 설계, API 연동, JSON 결과 검증
C (화면 담당)	UI 개발	Streamlit 화면, 표·차트 출력, 업로드 기능
D (데이터/테스트)	데이터와 품질	샘플 강의계획서 수집, 정확도 테스트, 오류 기록, 발표 자료 정리
