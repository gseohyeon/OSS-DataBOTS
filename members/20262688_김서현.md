# 김서현 활동 기록

- 학번: 20262688
- 이름: 김서현

## 활동 기록

### 1~3주차

- GitHub 팀 저장소 생성
- 팀원 구성 및 기본 정보 정리
- `README.md` 작성
- 팀원별 개인 활동 기록용 `.md` 파일 생성
- `members` 폴더 및 기본 파일 구조 구성

### 4~5주차

- 팀 프로젝트 진행 방식에 대한 회의 진행
- 보고서 작성 방식과 소프트웨어 개발 방식의 특징 비교
- 팀원들의 의견을 정리하여 소프트웨어 개발 방식으로 프로젝트 방향 결정
- 회의 내용을 정리하여 Markdown 형식의 회의록 작성
- 이후 프로젝트에서 사용할 GitHub 활동 기록 방식 정리
- 팀원들에게 개인 `.md` 파일 작성 방법 안내
- `Edit this file`을 이용한 Markdown 파일 수정 방법 설명
- `Commit changes`와 Commit message 작성 방법 안내
- 각 팀원이 자신의 GitHub 계정으로 직접 활동 기록을 남기는 방법 공유
- 팀원별 활동 기록과 회의 기록을 지속적으로 관리할 수 있도록 저장소 구조 정리

### 배운 내용

GitHub 저장소를 직접 생성하고 README와 Markdown 파일을 이용해 팀 프로젝트의 기본 구조를 구성하는 방법을 익혔다.

또한 팀 회의를 통해 프로젝트 진행 방향을 정하고, 그 과정을 회의록으로 남기면서 GitHub가 단순히 파일을 저장하는 공간이 아니라 프로젝트 진행 과정도 기록할 수 있는 도구라는 점을 알게 되었다.

팀원들에게 Markdown 작성과 Commit 방법을 설명하면서 GitHub를 활용한 기본적인 협업 방식도 익혔으며, 각자의 활동을 꾸준히 기록하는 것이 중요하다는 점을 배웠다.
